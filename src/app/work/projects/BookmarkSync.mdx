## 项目简介

[BookmarkSync](https://www.bookmark-sync.top) 是一款跨浏览器书签云同步产品，由浏览器扩展 + 云端同步服务组成。安装扩展、登录账号后，Chrome、Edge、Firefox 三家的书签会合并成一棵树，在任何浏览器里整理书签，改动都会同步到所有设备。

它要解决的是浏览器原生同步的几个老大难：各家浏览器的书签互不相通、重命名/移动文件夹后子书签丢失或层级错乱、删除的书签又"复活"、两台设备同时编辑时一边被另一边静默覆盖。

官网：[www.bookmark-sync.top](https://www.bookmark-sync.top)

## 核心能力

### 真树结构同步

同步引擎以完整的树结构保存书签，而不是把层级压平成路径字符串。重命名、移动、合并文件夹时，所有子节点和层级原样保留——不会出现"改了个文件夹名，里面的书签全没了"。

### 精确删除，永不复活

删除操作通过墓碑（tombstone）机制在设备间传播：在 A 设备上删掉的书签，绝不会从 B 设备的陈旧数据里"复活"回来。

### 多设备自动合并

两台设备同时增删改书签时，由智能三方合并（three-way merge）裁决：双方的修改都保留，不做盲目的整树覆盖；离线期间的编辑会在重新联网时自动合并。

### 顺序跟着走

每个书签都携带排序键，同步时收敛到一致顺序——在一台设备上拖拽排序，其他设备保持同样顺序，不会被打乱成内部 ID 顺序。

### 端到端加密

端到端加密默认开启：每条书签操作先在本地加密再上传，服务器上只有密文，服务方自己也读不到你的书签。密钥不经手服务器；换新设备时登录同一账号、输入同一口令即可，无需手动导出密钥。

### 同步空间与设备管理

每个同步空间是一棵独立的书签树，可以绑定不同的浏览器 Profile——工作收藏和生活收藏互不干扰。登录过同步的浏览器会自动注册为设备，可随时查看、重命名或解绑。

## 技术要点

- **浏览器扩展** — 覆盖 Chrome、Edge、Firefox 三大内核系浏览器
- **云端同步服务** — 操作日志式同步 + 服务端日志压缩（compaction 只合并历史操作记录，不删书签）
- **端到端加密** — 本地加密、云端密文存储，口令即唯一解密钥匙
- **冲突解决** — 墓碑删除 + 三方合并 + 分数排序键（fractional sort keys）收敛
