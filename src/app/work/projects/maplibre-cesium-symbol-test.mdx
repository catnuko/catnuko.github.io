## 演示说明

本页面在 Cesium 三维地球上叠加 MapLibre Vector Tile 矢量注记（Symbol），展示两者的融合效果。

### 功能

- **3D 地球** — 基于 Cesium 的三维场景，支持自由旋转、缩放
- **矢量注记** — 使用 MapLibre VectorTileExtension 加载 OpenMapTiles 风格的地图注记（地名、POI 等）
- **点击交互** — 点击任意注记，在控制台输出其 Cross Tile ID
- **GUI 控制** — 控制注记显隐、瓦片显示

### 技术栈

- **Cesium** — 三维地球渲染引擎
- **MapLibre VectorTileExtension** — 矢量瓦片注记扩展
- **Turf.js** — 地理空间分析
- **dat.GUI** — 可视化控制面板
